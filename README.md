# charleysanchez.github.io

Personal site, built with Jekyll on GitHub Pages. No theme; the layout is in `_layouts/default.html` and all styles are in `assets/css/site.css`.

Most updates are one entry in a data file:

- `_data/news.yml`: news items (newest first, text is Markdown)
- `_data/papers.yml`: papers and reports ("C. Sanchez" is bolded automatically)
- `_data/projects.yml`: projects; thumbnails are 480x360 JPEGs in `assets/img/thumbs/`

Bio, research, experience, and education are written directly in `index.md`. The longer story is in `about.md`.
